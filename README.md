# Lucas.Dev 🌵

Portfólio pessoal com estética desértica/Nordeste e humor.

## Como usar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie estes três arquivos para o repositório:
   - `index.html`
   - `style.css`
   - `script.js`
3. Entre na Vercel e escolha **Add New → Project**.
4. Importe o repositório do GitHub.
5. Para esse projeto, não precisa de build command.
6. Clique em **Deploy**.

## Antes de apresentar
Troque:
- `LUCAS.DEV` pelo nome/username que quiser.
- links do GitHub/LinkedIn.
- `seuemail@email.com`.
- os projetos de exemplo pelos seus projetos reais.

O site é estático, então funciona muito bem como primeiro portfólio.
